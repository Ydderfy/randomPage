# RandomPage 🎲

Un site web moderne et responsive créé avec HTML5, CSS3 et JavaScript.

## 📁 Structure du Projet

```
randomPage/
├── index.html          # Page d'accueil
├── forum.html          # Page forum
├── contact.html        # Page contact
├── css/
│   └── style.css       # Styles CSS
├── js/
│   └── main.js         # JavaScript
└── README.md           # Documentation
```

## 🚀 Fonctionnalités

- **Design Responsive** : S'adapte à tous les écrans (mobile, tablette, desktop)
- **Navigation Fluide** : Menu hamburger sur mobile, navigation sticky
- **Forum Interactif** : Filtrage par catégorie, recherche, création de sujets
- **Formulaire de Contact** : Validation et feedback utilisateur
- **Animations** : Effets de scroll, transitions fluides
- **FAQ Accordéon** : Section questions fréquentes interactive

## 🛠️ Technologies Utilisées

- HTML5
- CSS3 (Flexbox, Grid, Variables CSS)
- JavaScript (ES6+)
- Font Awesome (icônes)
- Google Fonts (Poppins)

## 📦 Installation

1. Clonez ce dépôt :
```bash
git clone https://github.com/votre-username/randomPage.git
```

2. Ouvrez `index.html` dans votre navigateur

## 🌐 Hébergement sur GitHub Pages

1. Créez un nouveau dépôt sur GitHub
2. Poussez votre code :
```bash
git init
git add .
git commit -m "Premier commit - Site RandomPage"
git branch -M main
git remote add origin https://github.com/votre-username/randomPage.git
git push -u origin main
```

3. Activez GitHub Pages :
   - Allez dans **Settings** > **Pages**
   - Source : Sélectionnez `main` branch
   - Cliquez sur **Save**

4. Votre site sera accessible à : `https://votre-username.github.io/randomPage/`
